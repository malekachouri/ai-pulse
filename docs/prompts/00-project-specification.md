# AI Pulse: project specification

The vision and stack the nine prompts implement. It is context for you, not a prompt to send:
prompt 01 repeats what Claude needs.

We'll treat this as a real production-oriented project, with architecture, database, backend, frontend, AI processing, automated data collection, testing, Docker and deployment.
The project will be called AI Pulse.
## 1. Project specification
AI Pulse

AI & Technology Intelligence Platform

A centralized platform that monitors:
- AI models, releases and research.
- AI tools, frameworks and GitHub repositories.
- Bugs, software failures and production incidents.
- Cybersecurity vulnerabilities and CVEs.
- Cloud, Kubernetes, DevOps and infrastructure updates.
- Daily AI-generated intelligence briefings.

Technology stack
| Component | Technology |
|---|---|
| Frontend | Next.js + TypeScript |
| Styling | Tailwind CSS + shadcn/ui |
| Backend | FastAPI + Python |
| Database | PostgreSQL + pgvector |
| ORM | SQLAlchemy + Alembic |
| AI | LLM API + Ollama support |
| Collection | RSS + GitHub + official APIs |
| Background jobs | Celery + Redis |
| Infrastructure | Docker |
| Monitoring | Prometheus + Grafana |
| CI/CD | GitHub Actions |
